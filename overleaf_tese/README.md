# Projeto para Overleaf

Este diretório é um projeto LaTeX autónomo e pode ser carregado diretamente no Overleaf.

1. Cria um projeto vazio no Overleaf.
2. Carrega os ficheiros main.tex e references.bib.
3. Seleciona pdfLaTeX e compila. Se necessário, seleciona BibTeX como ferramenta bibliográfica.

O texto distingue factos já produzidos nos notebooks de decisões ainda por validar. As próximas secções a completar são a comparação de embeddings, a seleção de parâmetros e a validação dos tópicos e relações temporais.
